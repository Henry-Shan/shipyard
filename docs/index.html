A QA tester just filed 18 findings. Watch them become pull requests.

The scenario. Castaway Studio is a podcast-hosting app. A tester finished an end-to-end pass on staging and wrote everything up: silent upload failures, a timezone bug in scheduling, a guest who can see the billing page, feature asks, two things already fixed last week, and two things nobody should touch yet.

What runs. /manager reads the write-up, works out which items are real work, and keeps three /ship-task workers busy. Each worker takes one task into its own git worktree, writes a failing test first, implements, passes a verify gate and an independent feature test, and opens a PR. New reports keep arriving. You only get pulled in when a run has a question it can't answer from the code — and you are the only one who merges.

Everything here is simulated in your browser. The triage rules for risky work (auth, billing, migrations, deletions) are the real ones.
